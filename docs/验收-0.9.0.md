# 0.9.0 主题与四季动画验收

本版移除山水四季及四张图片资源；旧设置与旧备份在载入时自动改为四季。新增管理员主题包导入、整站预览、保存、导出和开发文档。Agent 保持 0.2.1，WSS、SSH/SFTP 协议与安装方式不变。

## 功能验证

- Rust 主控 42 项测试、前端 7 项测试通过；PHP、安装脚本及更新工具语法检查通过。
- 上传示例主题后仅本页预览，退出预览恢复原主题；保存后访客可见，导出再导入与保存内容一致。
- 明暗配色、移动端布局、背景色、开发文档与示例下载、内置主题切换、陈旧版本保存冲突均通过浏览器验证。
- 真实测试节点 SSH 连接与关闭正常，取消文件选择不关闭终端；未重新引入终端保活。
- 验证完整一分钟的春夏切换、夏秋冬及冬春衔接、暂停和播放、可见性事件暂停、减少动态效果默认暂停、切换主题释放动画及画布。
- 暗色与模糊预先写入风景缓存；换季只合成两张缓存图像，不重画树木等几何。单张显示画布的分辨率约限于 65 万像素，透明卡片无需对运动背景逐帧执行模糊。

## 动画性能

Chrome 153 软件渲染，同屏 13 张仅在测试浏览器生成的卡片，每档采样约 8 秒。桌面尺寸 1440×1000，手机尺寸为 390×844 的浏览器模拟。

| 项目 | 0.8.1 背景实际更新 | 0.9.0 背景实际更新 |
| --- | ---: | ---: |
| 桌面尺寸 | 1.0 次/秒 | 57.9 次/秒 |
| 手机尺寸 | 1.0 次/秒 | 58.5 次/秒 |

完整换季观察窗口含 6 秒渐变，平均 59.0 FPS，帧间隔 P95 为 16.8 ms。另以实时时钟从过渡前开始的短测，渐变期间约 58.8 FPS。数据来自实际测量，目标为 60 FPS；设备性能、屏幕刷新率、省电与系统减少动态效果设置会影响结果。未把手机尺寸模拟当作手机真机测试。

## 快速压力回归

隔离实例、回环 HTTPS/WSS、200 个模拟 Agent 同时上报与 200 个客户端并发请求，测量约 20 秒：

- 15,078 次请求，错误 0 次；成功吞吐 745.3 请求/秒，P95 343.4 ms。
- 最终 200 个节点在线，200 个最新上报匹配；无 OOM。
- 主控 CPU 平均占单核 42.0%，RSS 峰值 19.4 MiB。

这是有 CPU/内存上限的快速回归，不是互联网访问速度、长时间稳定性或最大容量承诺。压测服务使用独立端口、状态与 Nginx 临时目录。

## 安全检查

- 管理员鉴权、CSRF、跨站请求拒绝、Secure/HttpOnly/SameSite Cookie、CSP 与私有目录隔离检查通过。
- 22 类非法包或超限请求被拒绝，包括未知字段、错误版本、路径字段、运行中版本、嵌套元数据、样式注入、外部资源、透明正文配色与伪造图片。
- 主题名中的 HTML 以文字显示；导入不执行代码、不保存文件路径。图片按内容解码后重新编码，限制尺寸、内存与并发。
- npm 全依赖审计 0 项；Rust Agent 依赖审计 0 项；源码 Gitleaks 未发现泄漏。
- Rust 主控仍有已有的 **RUSTSEC-2023-0071（rsa）** 上游告警；并非本版新增，也未宣称修复。现有 SSH 管理密钥使用 Ed25519，该告警涉及的 RSA 私钥操作不在当前正常路径。详见 [安全边界](RUST-SECURITY.md)。

amd64 已在测试环境实测；ARM64 完成交叉编译，本轮未进行 ARM64 真机验收。源码包不包含真实账户、节点或密钥；发布包使用既有 Ed25519 发布密钥签名，并校验所有归档文件 SHA-256。生产部署后的在线节点与 SSH 检查另行记录，避免将测试站结果充作生产结果。
