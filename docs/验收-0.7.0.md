# 羽迹探针 0.7.0 验收记录

日期：2026-10-01。主控与界面 0.7.0，Agent 0.2.1。开发、编译、写入测试与虚拟机均在开发服务器完成；生产更新使用签名包并保留原有状态。

## 变更

- 手机终端快捷栏：Ctrl、Tab、Esc、Ctrl+C、方向键、粘贴、当前终端内容查找。方向键支持长按，切换标签、断开或页面进入后台后停止重复输入并清除 Ctrl 状态。适配手机键盘缩小可视区域。
- 续费周期：按月、季度、年及自定义天数，保留月末锚点；旧节点默认仍为固定 30 天。确认续费时可填写供应商实际到期时间。
- 续费金额与支出汇总：金额以字符串输入、整数最小货币单位计算，按币种分别汇总月/年预算、未来 30 天下一次到期金额及逾期金额。仅管理员可见，未设置金额不会作为免费服务器处理。
- 主控与 Agent 扩展 Linux/systemd 安装支持，分别识别 apt/dnf、PHP-FPM 路径、服务账户、CA 和依赖工具。保持 SELinux enforcing，处理安装、升级与回滚的文件标签。
- 去除管理员登录窗口的“管理会话通过 HTTPS 保护。”文案。
- 替换被上游撤回的 yoke-derive 0.8.3 为 0.8.4；WSS 协议、节点认证和 SSH/SFTP 入口保持兼容。

完整范围见[系统支持](系统支持.md)、[功能说明](功能-0.7.0.md)、[Linux 一键安装](Linux一键安装.md)。

## 主题、卡片与详情

四套主题保存及访客同步通过；背景和图标经过真实上传、解码、重新编码、显示测试，预览不会写入正式配置。验证非法 CSS、外部资源、标签注入、伪造图片、非法参数、缺少 CSRF 和过期版本提交均被拒绝。页面监测轮询不会重复下载未改变的背景图片。

浏览器隔离生成六张布局卡片，分别包含启用/未启用 Swap、离线、长名称及不同分组；四套主题在桌面与手机尺寸下共 8 组等高、Swap 位置及横向溢出检查通过。该布局测试未向真实站点添加模拟节点。真实测试节点的“进程与服务”按钮已移到通讯延时下方并能打开进程面板。四套主题的深色模式和管理编辑页响应式检查也通过。

## 快速压力测试

200 个模拟节点持续上报，同时 200 个并发客户端通过 PHP 网关访问，持续 20 秒：

| 指标 | 结果 |
| --- | --- |
| 完成请求 | 15,530 |
| 平均吞吐 | 765.77 请求/秒 |
| 请求错误 | 0 |
| p95 延迟 | 375.12 毫秒 |
| 最新数据匹配 | 200/200 |
| 节点上报失败/落后 | 0 / 0 |
| 主控平均 / 峰值 RSS | 19.06 / 19.16 MiB |
| 主控 CPU | 约单核 37.32% |

本轮 PHP 网关限制为单核配额；该结果不是 Rust 主控最大吞吐上限。短时压测不能替代长时间稳定性测试。数据来自包含主题功能的最终 Rust 二进制，使用隔离测试实例；压测期间开发服务器还进行了浏览器回归，因此这是本轮环境的短时成绩，不是与旧版 Go 的受控对比。

## 安全检查与限制

- npm audit：0 项漏洞。
- Agent cargo audit：0 项漏洞、0 项撤回依赖告警。
- 主控 cargo audit：仍有既有 RUSTSEC-2023-0071，涉及 rsa 0.10.0-rc.18 的私钥时序风险；上游尚无标记为已修复的版本。现有面板使用 Ed25519 客户端私钥，RSA 仅作 SSH 服务端公钥验签，具体边界见 [RUST-SECURITY.md](RUST-SECURITY.md)。未将依赖告警删除或宣布已修复。
- 源码 Gitleaks：0 条发现。
- 发布包 SHA-256、Ed25519 签名、路径、私有状态排除与静态资源引用复核见附件 verification-0.7.0.json。

这是本次代码审阅、扫描与实测范围，不代表第三方渗透测试或“绝无漏洞”保证。生产中仍需更新系统与浏览器，并妥善保管管理员、恢复密钥和备份。
