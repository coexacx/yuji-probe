# 四季背景

0.9.0 保留「四季」水彩山湖主题，移除「山水四季」及其四张图片资源。旧设置与旧备份中的山水四季自动改为四季。

风景由 `source/src/seasons.mjs` 的 Canvas 绘制，树枝、山脊、湖岸与房屋位置跨季节保持一致。两张画布分别缓存当前与下一季风景，只在季节轮换或视口尺寸变化时绘制。每季 60 秒，最后 6 秒交叉淡入下一季。

花瓣、萤火、落叶、雪片、湖面涟漪与缓慢运镜使用浏览器 Web Animations。换季合成与季节色彩由与显示器同步的动画时钟控制，目标为 60 FPS 的连续播放效果，不需要下载整段视频。实际流畅度受设备性能、浏览器与屏幕刷新率影响。

页面底部可暂停；切到后台时停止动画和时钟；系统减少动态效果设置默认暂停。粒子、涟漪与运镜由原生浏览器动画改变 transform 和 opacity。风景的几何只绘制一次；换季时在一张不超过 65 万像素的不透明画布上合成两张缓存，不叠加多层全屏透明表面。暗色与模糊效果在风景缓存中提前处理；卡片保留透明底色、边缘与阴影，不对运动背景逐帧执行背景模糊。
