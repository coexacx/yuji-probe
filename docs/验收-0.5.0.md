# 0.5.0 开发验收记录

测试日期：2026-09-30。主控/UI 0.5.0，Agent 0.2.0。以下只列实际完成的检查，短时压测不等同长期稳定性认证。

## 吞吐对比

同一开发主机，隔离 Nginx TLS、PHP 网关、控制器进程，主控均限制 1 核、512 MiB。200 个模拟 Agent 每秒上报，200 个独立来源客户端持续请求公共看板。按 Go → Rust → Rust → Go 顺序，各测 20 秒，保留原有每 IP 120 次/分钟限制。原始指标见 performance-0.5.0.json。

| 两轮平均 | Go 基线 | Rust 0.5.0 |
| --- | ---: | ---: |
| 成功请求/秒 | 289.79 | 821.59 |
| P95 延迟（毫秒，各轮 P95 的均值） | 773.07 | 290.62 |
| 主控 CPU（占一核） | 99.93% | 47.72% |
| 主控 RSS（MiB） | 39.91 | 18.55 |

本场景吞吐约为 Go 的 2.84 倍。四轮均无请求错误、Agent 连接失败、OOM；结束时 200 节点在线且最新序号全部匹配。Rust 期间 PHP 已接近一核限制，后续扩容需同时考虑网关，不代表所有场景都可达到相同比例。

首次 45 秒试验触发原有访客限流（HTTP 429），不能算作零错误吞吐成绩。最终缩短双方测量窗口，未降低正式环境限流。公共快照最多缓存 1 秒，管理员数据与权限检查不缓存共享。再次用最终发布二进制完成同条件四轮复测，记录中的 Rust SHA-256 与发行版一致。

## 功能和故障路径

- 81 项原有浏览器/API 回归：安装向导、身份和 CSRF、私有路径、MFA 重放、节点与命令、通知参数等。
- 12 组新功能检查：会话撤销、权限策略、备份下载和计划、错误口令与篡改拒绝、恢复、恢复码一次性与轮换、离线删除等。
- 真实 Debian 测试节点：WSS、终端、SFTP 编辑及无备份、只读和监控权限、撤销会话关闭远程连接、历史切换、手机界面。
- 双向跨域迁移：停止旧主控，新主控仅凭备份里的受限恢复身份主动接管；验证旧 Token 与旧 SSH 恢复钥匙失效。
- 目标不可达重装回退：旧 Agent 配置、密钥与旧 WSS 连接恢复；更换为可达新域名后重装成功。
- 在线移除：服务停用、配置与专用密钥清除，独立公钥、测试文件、原有应用进程保留；离线移除：远端文件摘要保持不变，无远程队列，旧凭据拒绝。
- 完整真实签名安装包在测试站升级、健康检查、手动回退通过，保留站点、管理员、节点凭据及独立 PHP 池。
- 旧 Agent 0.1.3-rust.1 经已有 WSS/SSH 自动升级 0.2.0；签名 Agent 升级与回退均经真实节点检查。
- root MFA 重置：6 项，运行锁、非 root、确认、撤销旧身份、保留密码和所有权。
- root 更新器：10 项，签名绑定、下载域名/协议、路径穿越、符号链接、重复条目、私有状态、部分快照失败和健康失败恢复等。
- Rust Agent 18 项、主控 23 项单元测试；主控包含流量跨重启/重置/账期/网卡、持续阈值/恢复/重复/聚合/维护、恢复历史写入竞争。
- 两种架构编译；amd64 真实运行，arm64 仅交叉编译，未宣称实机验证。

## 扫描结果

- Agent Cargo Audit：0 个已知漏洞，0 告警。
- 主控 Cargo Audit：保留 1 个上游 RSA 时序侧信道告警 RUSTSEC-2023-0071，没有上游修复版本。受管私钥限定 Ed25519，RSA 仅用于已有服务器主机公钥验签；这是当前可达性判断，详见 RUST-SECURITY.md。
- npm 审计：0 个已知漏洞。Clippy -D warnings、PHP 语法、ShellCheck、Python 更新器负面用例通过。
- Gitleaks 最终源码 0 命中；完整安装包 5 条命中，均经逐条核对为 SHA256SUMS.json 的有效文件摘要。安装包全部摘要验证通过，无运行状态或真实凭据。未把已知依赖告警隐藏为零漏洞。

扫描无法保证不存在未知漏洞。长时间网络抖动和大规模历史增长仍需持续观测；首次监控前和离线期间跨重启丢失的计数不能从当前网卡计数器补算。
