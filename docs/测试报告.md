## 快速压测

隔离实例中进行 10 个模拟 Agent / 10 个客户端（15 秒）和 30 个 Agent / 30 个并发客户端（30 秒）两阶段测试，累计 1,050 次 HTTP 请求全部返回 200，Agent 失败数为 0，累计发送 1,160 条监控消息。较高负载阶段 P95 为 99.92 ms、P99 为 127.79 ms。PHP 与压测进程分别限制为 1 核、384 MiB。该负载是受控短测，不作为极限节点数或真实公网延时承诺。

真实双 SSH 会话中突发 96 个文件请求：24 个完成，72 个按设计返回忙碌，无协议错误；终端仍可响应。详见 `rust-tests/sftp-load.json`。有界队列拒绝超量请求是保护行为。

Rust 与 Go Agent 的同机等配额比较见 [Agent 对照报告](RUST-AGENT-COMPARISON.md)：等负载 RSS 降低约 76.8%，CPU 用量降低约 34.0%，amd64 文件缩小约 57.9%，短时饱和吞吐提高约 41.2%。该数据属于合成隧道测试，不是公网带宽或完整 SSH 文件传输吞吐。

## 安全扫描与代码复核

- Rust Agent Cargo Audit：158 个依赖，0 个已知漏洞、0 个告警；Clippy 与单元检查通过。
- Rust 主控 Cargo Audit：318 个锁定依赖，保留 **1 个上游告警 RUSTSEC-2023-0071 / CVE-2023-49092**。其余告警为 0。前端 npm audit 已知漏洞为 0。
- RSA 告警涉及私钥运算时序泄漏，上游没有修复版本。本程序受管 SSH 私钥仅生成和接受 Ed25519，首次部署使用密码认证；RSA 仅用于远端主机公钥验签，当前程序不进入该告警的 RSA 私钥运算路径。该判断限定于当前版本，不能称为依赖已修复或零告警。完整依据见 [Rust 安全说明](RUST-SECURITY.md)，原始 Audit JSON 随包保留。
- 复核覆盖会话与 CSRF、密钥加密、SSH 指纹、终端票据、WSS 消息与队列上限、SFTP 路径/版本/元数据、退出和取消资源回收、安装私有目录保护。扫描覆盖范围未发现未处理的可复现利用问题；这不等于不存在未知漏洞。
- 已修复并回归：`providerURL` 的历史字段兼容、监督进程停止/唤起时锁竞争、SSH/SFTP 取消任务的资源回收，以及损坏主机指纹文件的拒绝策略。
- 发布包不含真实 `storage`、管理员账户、密码哈希、私钥、服务器 Token、Telegram Token 或生产服务器列表；包内哈希清单用于核对文件完整性。

## 测试边界

- 生产实际运行和浏览器验收为 Linux amd64；ARM64 已交叉编译并校验静态产物，**尚未在 ARM64 真机运行验收**。支持 Debian/Ubuntu 部署不代表每一个发行版、内核与 SSH 配置都已覆盖。
- Go/Rust 24 小时对照观测仍在运行。此报告采样时已约 **1.50 小时**，两者均为 0 协议错误，观测结果保存在 `rust-tests/node-final-check.json`。**不能将这份报告称为 24 小时稳定性通过**。
- Telegram 事件生成、聚合、状态持久化、重试与取消路径完成本地测试，生产配置已保留；本轮没有向真实收件人额外发送测试消息。
- 主控终止/唤起在隔离环境验证；本轮未进行生产整机重启或真实断电测试。

原始脱敏证据与结构化汇总位于 `docs/rust-tests/`。本报告只描述上述版本与测试条件；后续修改、运行环境变化和新的上游公告需要重新评估。
