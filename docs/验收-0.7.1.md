# 0.7.1 验收记录

日期：2026-10-01。界面与主控 0.7.1，Agent 保持 0.2.1。开发与真实节点回归在测试站完成。

## 本次交付

- 新增“四季”和“山水四季”。前者为水彩山湖，后者为同一视角的写实山湖，素材从本站加载。
- 每季 60 秒，春、夏、秋、冬一轮 240 秒。最后 6 秒渐变衔接下一季，冬季可连续回到春季。
- 看板、后台卡片、详情与终端采用对应主题表面。六套主题均可选择；默认主题的终端配色保持原样。
- CPU 曲线、正常资源进度条、卡片数值及网卡速率跟随季节变色。浅色/深色分别配色；高负载、在线与离线状态保留既有语义颜色。
- 非默认主题的 SSH、终端标签、手机快捷工具栏、SFTP 目录及编辑区跟随主题，切换外观保留正在连接的 SSH 会话。
- 页脚可暂停背景；系统减少动态效果设置会暂停播放。页面隐藏时停止动效，切换主题会清理画布、图片、计时器与监听器。

## 实测与构建

- Rust 主控 34 项测试通过，fmt 与 Clippy（warnings 作为错误）通过。
- 前端 6 项测试通过：60 秒边界、跨年循环、渐变连续性、异常时间、终端主题及季节指标颜色。
- Linux amd64、arm64 主控均完成 musl 构建。ARM64 本次为交叉编译验证，未新增 ARM64 真机验收。
- 测试站 11 个后台页面的透明表面检查通过；桌面与 390px 手机视口无横向溢出。
- 同一真实测试节点建立一个 SSH 会话，轮换六套主题及浅深模式；连接与 shell 变量保持正常。SFTP 成功浏览并读取系统文本文件，编辑区颜色跟随主题。未以修改系统文件作为本次 UI 回归手段。
- 两套季节主题各通过一轮 240 秒虚拟时钟检查，四季颜色不同且首尾一致，警告颜色不被覆盖。
- 山水四季另通过真实时间完整循环，四个周期分别为 60.049、59.981、59.987、60.058 秒。暂停/恢复、系统减少动画、页面隐藏事件模拟均通过；无页面脚本错误或外站资源请求。
- 多次快速切换主题后，无残留季节画布、控件或动态指标样式。

## 动画资源记录

测试环境：开发服务器上的无硬件加速 headless Chrome，1440 × 1000 视口，13 张仅存在于浏览器内的测试卡片，不向主控写入虚拟节点。后台监测仍正常轮询。

| 测量项 | 最终构建 |
| --- | ---: |
| 完整循环期间 Chrome 全部进程 CPU，单核百分比 | 35.52% |
| 页面主线程忙碌比例 | 8.68% |
| 暂停动效后的 Chrome CPU，单核百分比 | 8.43% |
| JS 堆峰值 | 4.69 MiB |
| Chrome 各进程 RSS 求和峰值 | 1216.64 MiB |
| 背景画布像素 | 1,101,625 |

RSS 求和包含浏览器、渲染器及软件图形进程，共享页可能重复统计，不能视为页面独占内存。此处不是物理手机或硬件 GPU 的性能成绩。早期同场景动画方案约 104% 单核，最终采用缓存风景、缓慢的低频环境动效及换季期间按需绘制，减少持续重绘。透明背景在软件渲染环境仍有成本，可使用页脚暂停。

四张写实 WebP 合计 1,701,872 字节，按内容哈希缓存。低频环境动效不以高帧率视频播放为目标；完整循环以页面可见且播放的时间计算。

## 安全复核

已验证以下边界：

- 未登录不能读取管理信息或申请终端票据。
- 管理会话 Cookie 使用 Secure、HttpOnly 和 SameSite；退出后管理访问失效。
- 缺少 CSRF 或来自其他 Origin 的配置请求被拒绝。
- 主题只接受固定枚举，图片伪装与 SVG 上传被拒绝；局部样式拒绝外部资源、脚本与定位注入。
- CSP、禁止框架嵌入及 nosniff 响应头正常。
- 配置、源码、Git、运行状态等私有路径不可通过站点读取。
- 公共节点接口不暴露 SSH、供应商、租约、密钥等管理字段。
- 已安装站点不能再次进入安装写入流程。
- 动效只使用内置代码和本站资源，无外部图床、字体或生成服务依赖。
- 终端改动只更新配色；原有 OSC 剪贴板、链接及窗口操作拦截保持有效。

源码 Gitleaks 扫描无密钥泄露发现；最终包检查签名、内容 SHA-256、资源依赖及私有目录排除。包清单中的随机外观 SHA-256 字符串需与真实文件摘要比对，不能把此类误报计为已泄露凭据。

依赖审计：前端 0 条、Agent 0 条，主控仍有已记录的 **RUSTSEC-2023-0071 / rsa 0.10.0-rc.18**，本次未新增依赖。项目 SSH 客户端密钥使用 Ed25519，RSA 用于远端公钥验证，不走告警涉及的 RSA 私钥运算路径。详见 [Rust 安全说明](RUST-SECURITY.md)。这不等同于宣称依赖不存在漏洞，扫描也不构成“绝对无漏洞”的保证。

自动化虚拟时钟测试曾因密集请求触发测试站限流，已将虚拟时间下的监测轮询限定为浏览器本地快照，待限流窗口恢复后真实功能回归通过；未放宽服务端限流。
