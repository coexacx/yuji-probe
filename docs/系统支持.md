# 系统与架构支持

主控和 Agent 使用预编译 Rust 静态二进制，支持 amd64 / x86_64、arm64 / aarch64。以下安装流程需要完整 Linux 系统与 systemd，容器中只有 systemctl 命令但没有 systemd 服务管理器不满足条件。

| 发行版 | 主控一键安装 | Agent 自动部署 |
| --- | --- | --- |
| Debian | 12、13 | 11、12、13 |
| Ubuntu | 22.04、24.04、26.04 | 20.04、22.04、24.04、26.04 |
| Rocky Linux | 9、10 | 8、9、10 |
| AlmaLinux | 9、10 | 8、9、10 |
| CentOS Stream | 9、10 | 9、10 |
| Fedora | 42、43、44 | 42、43、44 |
| Amazon Linux | 使用手动安装环境检查 | 2023 |

这是代码支持范围。实际完成安装、登录、WSS 和 SSH/SFTP 验收的版本见[本版验收报告](验收-0.7.0.md)，未把全部发行版本或 ARM64 真机称为已经验收。系统应继续获得发行版的安全更新；兼容旧版本不代表其上游仍提供免费维护。

主控一键安装会选择 apt 或 dnf，按发行版生成 PHP-FPM 池路径、socket、服务名及 Nginx 配置。RPM 企业发行版从其签名软件源安装 epel-release，以提供 Certbot。安装器保留 SELinux enforcing，使用限定目录及内部端口的策略；不关闭防火墙，也不更改 SSH 配置。自动安装拒绝覆盖已有宝塔、Nginx 站点及面板数据。

Agent 检查系统和架构后按需补齐 CA、Python 3、tar/gzip、用户管理工具，保留 WSS 证书验证、节点独立凭据、受限运行用户与 systemd 沙箱。安装包由主控校验签名后上传，不在节点编译，也不开设 Agent 公网监听端口。

Windows、macOS、FreeBSD，以及不运行 systemd 的 Alpine/OpenRC 安装不在本版本范围。主控的 Nginx + PHP 8.0+ 手动/宝塔安装入口继续保留；普通用户无需数据库、Rust 或 Node.js。
