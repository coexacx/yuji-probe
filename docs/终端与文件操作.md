# 终端保活、文件续传与命令接入

## 终端会话

安装在服务器上的 tmux 保留远端 shell。面板为每个安装实例使用独立的 tmux socket，随机会话名称不会与管理员自己创建的会话混用。

- 标签上的 ×、终端右上角「关闭」、以及「结束会话」：结束对应 SSH 和保活会话。再次连接新建 shell。
- 「保留并退出」：断开连接，保留远端终端；重新打开同一服务器，在选择框选择恢复的会话。
- 网络断开、手机切到后台或关闭网页：按连接中断处理。页面仍打开时最多自动重连 5 次，之后可以手动恢复。
- 离线保留 30 分钟。一个面板最多 8 个保活会话，浏览器工作区最多 4 个标签，同一节点最多 2 条 SSH 连接（含运行状态检查）；超过保留时间将结束会话。
- 退出管理员登录、撤销设备或更改账户凭据会撤销对应会话；服务器离线时清理任务等待服务器重新上线。不会终止其他 tmux socket 或独立运行的 systemd/nohup 服务。
- 主控进程重启后可以重新登录，手动恢复尚未到期的远端会话。被控服务器重启无法恢复原来的进程。
- 新安装 Agent 自动补齐 tmux。旧节点没有 tmux 时仍能正常使用普通 SSH；按系统包管理器安装 tmux 后重新建立终端，即可启用保活。普通会话断开后不提供恢复。

恢复操作重新校验管理员身份、节点、会话状态及 SSH 主机指纹。同一会话不会同时被两个窗口接管。

## 文件传输

上传支持多选和顺序队列；每个终端最多排队 20 项，面板最多保留 64 条续传记录。单个文件上限 2 GiB。文件内容按小块处理，上传使用 File.slice；下载使用专用 Worker 以 128 KiB 分块写入 OPFS 浏览器磁盘缓存，完成后通过 Service Worker 的有界流交给浏览器保存，不在 JavaScript 中拼接整个文件或生成完整文件 Blob。

断线后队列暂停，恢复终端后点击「继续」。刷新页面后仍能找回当前保活会话的传输记录；上传需重新选择原文件，下载需保留原浏览器缓存。恢复前分别核验本地与远端已传输部分的 SHA-256，任何一方不匹配都会拒绝续传。上传完成后再次核对远端完整文件。

- 支持暂停、继续、取消和重新选择原上传文件。
- 下载需要浏览器支持 Service Worker、OPFS 及 Worker 中的同步文件句柄；缓存空间不足会暂停并提示。清除浏览器站点数据或浏览器回收缓存后，需重新下载。建议使用普通浏览器窗口：部分浏览器的无痕模式将缓存保留在内存中，无法获得相同的内存收益。
- 完成下载后由浏览器执行「保存文件」，实际保存位置由浏览器决定。取消浏览器保存后，可在队列重试并使用已校验的本地缓存；请等待完成提示后再关闭终端。
- 取消或主动结束保活会话会清理临时文件；网络中断保留续传信息。节点离线时远端清理等待 Agent 重新上线。缺少 tmux 的普通 SSH 会话不提供恢复，断线后只能尽力清理临时文件。
- 上传目标必须不存在，不覆盖同名文件。仅操作 SSH 用户有权限访问的文件。
- 续传服务的生命周期与保活会话一致；这不是在退出登录后继续运行的后台传输服务。

## 在线编辑

提供行号、常见语言语法高亮、查找替换、撤销/重做、自动换行和保存前差异预览。在线编辑仍限制为 256 KiB UTF-8 普通文件，不增加原文件备份。

保存时核对已读取版本、路径、权限和文件指纹；外部修改或另一个窗口保存会触发冲突检查。断线恢复后先核对远端版本，再允许保存；远端变化时保留当前编辑内容供手动合并。

Ctrl、Tab、Esc 等手机快捷按钮点击后有短暂反馈；Ctrl 仍是对下一个字符生效的开关，其选中状态单独保留。

## Agent 一次性接入

添加或编辑服务器时选择「一次性命令接入」，保存后复制命令，在目标服务器以 root 或 sudo 执行，无需将 SSH 密码交给面板。

- 命令有效期 10 分钟，只能领取一次；重新生成会使旧命令失效，也可以直接撤销。
- 命令中的临时凭据不放在 URL 中，服务端只保存其摘要。
- 领取使用 HTTPS，Agent 后续使用 WSS 及独立随机节点凭据。
- 主控验证发布清单的 Ed25519 签名和 Agent 二进制 SHA-256 后生成安装包。
- 目标服务器将本机 SSH 公钥提交给主控，之后 SSH/SFTP 必须匹配该主机指纹。
- 管理员退出登录、凭据变更或接入命令撤销会阻止尚未提交的接入。
- 重新接入离线节点会更换其通信令牌，更新主控域名和节点配置。在线节点需先停止原 Agent 再执行，避免覆盖正在使用的连接。
- 支持的 Linux/systemd 发行版及 amd64/arm64 架构与自动 SSH 安装相同。

接入命令属于临时凭据，仅在准备接入的服务器执行。下载或安装中断后，请在面板重新生成命令。
