# 主题与站点外观

管理员进入“管理后台 → 主题”，选择主题并保存。设置对全站生效；访客仍可通过右上角按钮选择浅色或深色。

## 四套主题

- **默认**：原有液态玻璃外观。
- **纯透明液态玻璃**：降低面板底色浓度，保留清晰边缘与背景模糊，适合搭配个人背景图。
- **简笔画**：纸面纹理、细线边框、不规则圆角与轻微错位投影。
- **纯二次元**：晴空、屋顶与樱色矢量插画，配合柔和的面板与强调色。背景为随源码发布的本站 SVG，无外部图片服务。

主题不改变监测、认证与终端协议。

## 自定义

**主题色**支持颜色选择器或六位十六进制输入，也可恢复对应主题的默认色。自定义颜色会应用到主要按钮、强调文字和监测图表；文字与按钮前景色按浅深模式调整。

**背景图**支持 PNG、JPG、WebP。浏览器接收最大 8 MiB 的原图并先压缩；服务端会按实际文件内容解码、限制尺寸与内存，再重新编码。最终背景上限 1.5 MiB，最长边 1920 像素。可调整遮罩和模糊。

**站点图标**支持同样的图片格式，服务端转换为最长边 192 像素的 PNG，保留透明通道。可同时用作页面左上角的站点标识。删除自定义图标后恢复程序默认图标。

图片在本站保存，作为配置的一部分进入加密备份；导入备份即可恢复。监测轮询仅带主题版本，不重复传输图片。浏览器按主题版本读取图片并在本地创建 Blob URL，未引入外部图床或追踪请求。

“预览整个站点”只改变当前页面，不影响其他访客；底部预览条可退出或保存。恢复默认设置先重置编辑内容，点击保存后才全站生效。

## 局部样式

在“局部样式覆盖”中填写受支持的 CSS，例如：

```css
.server-card {
  border-radius: 18px;
  border-color: #c7d7d4;
}
.node-title {
  font-size: 16px;
  font-weight: 600;
}
```

每组规则只能使用一个列出的选择器：

`.server-card`、`.node-title`、`.card-footer`、`.toolbar`、`.brand-mark`、`.brand-name`、`.footer`、`.admin-box`、`.node-dialog`。

支持属性：

| 属性 | 取值 |
| --- | --- |
| color、background-color、border-color | #RGB、#RRGGBB、#RRGGBBAA 或 transparent |
| border-radius | 0–40px，可写 1–4 个值 |
| border-width | 0–3px |
| font-size | 11–32px |
| font-weight | 400、500、600、700 |
| letter-spacing | 0–4px |

最多 4096 字节、16 组规则、每组 12 项属性。不支持导入样式、外部资源、脚本、属性选择器或改变定位/可见性的声明；服务器详情样式不会覆盖 SSH 工作区。保存和预览均由服务端校验。图片不接受 SVG 上传；内置 SVG 属于程序资源。

## 升级与故障处理

升级后保留当前外观，默认不会自动切换新主题。主题设置采用版本检查，多个管理页面同时编辑时，旧页面的保存会被拒绝，需要重新打开主题设置。

新主题随 0.7.0 完整包一起部署。无需数据库、额外 PHP 扩展、外部字体或 Node.js。后端图片处理已编译进 Rust 主控。源码构建使用 [image 的限额解码](https://docs.rs/image/latest/image/struct.Limits.html)与重新编码。

若自定义外观不合适，进入主题设置恢复默认并保存。终端仍使用适合代码阅读的独立深色配色。
