# Rust 版本安全边界与依赖告警

主控 0.5.1，Agent 0.2.0。应用源码禁止 unsafe；底层操作系统与密码库仍属于依赖信任边界。Rust 不能消除配置错误、权限滥用或所有逻辑漏洞。

## RUSTSEC-2023-0071 / CVE-2023-49092

主控依赖树中 `rsa 0.10.0-rc.18` 被 Cargo Audit 标记为 Marvin 时序侧信道告警，上游目前没有修复版本。原始扫描必须保留。官方公告：https://rustsec.org/advisories/RUSTSEC-2023-0071.html

本程序是 SSH 客户端，不提供 RSA 私钥解密或 RSA 私钥签名服务：首次部署使用密码认证；受管 SSH 私钥只生成 Ed25519；读取历史私钥后，在认证和建立 Agent 隧道之前检查算法，非 Ed25519 拒绝使用。RSA 特性仅为已有服务器的 RSA-SHA2 主机公钥验签保留。应用不配置 RSA 客户端私钥，也不支持导入任意管理私钥。

据此，当前应用路径没有该告警所描述的 RSA 私钥运算入口；这是针对当前代码和配置的可达性判断，不代表上游包已修复。未来增加 RSA 私钥、SSH 服务端或通用密钥导入时必须重新评审。

## 主要保护

- TLS 验证证书链与主机名，Agent 使用 WSS、独立节点密钥；禁止跳过证书验证。
- 管理密码 bcrypt，登录限流持久化；TOTP 启停需验证当前身份，动态码防重放。
- 管理接口要求有效会话；写操作校验 Origin 和 CSRF；Cookie 使用 Secure、HttpOnly、SameSite=Strict。
- 内部 HTTP 仅回环监听，PHP 网关凭证由私密主密钥派生；健康接口也验证凭证。
- 首次部署核对并固定 SSH 主机指纹；变更后拒绝连接。
- 终端票据短期有效、单次使用并绑定管理会话；退出、密码或 MFA 变更撤销活动终端。
- Agent 隧道仅连接节点回环 SSH 端口；消息大小、连接数、速率、队列、空闲和生命周期均有界。
- SFTP 按登录 SSH 用户权限操作；编辑仅限 256 KiB UTF-8 普通文件，校验版本冲突、保留权限与扩展属性，临时文件原子替换，不生成原文件备份。
- 节点凭据及 Telegram Token 使用 AES-256-GCM 加密，状态写入使用 0600 临时文件、同步与原子替换。
- 无数据库服务；storage 必须位于 public 外。独立 PHP 用户优于多站共享账户。

测试报告记录实际验证范围。快速扫描和压测不能保证不存在未知漏洞，也不等同于长期稳定性认证。


## 0.5.0 新增边界

- 恢复码高熵、单次使用、仅保存摘要；恢复登录撤销已有会话。root 重置 MFA 必须停本实例并手工确认。
- 加密备份具备完整性认证及解压大小限制；恢复采用持久提交日志，旧版历史字段在新版中仅兼容读取并丢弃。
- 跨域迁移必须匹配 SSH 指纹、恢复密钥和旧节点 Token，成功后轮换全部节点凭据。
- 在线删除只清理本 Agent 配置、公钥和服务；离线删除不排队执行远程命令。
- 根权限更新器不接受任意 URL、脚本或目录；发布签名与归档路径均验证，失败回退代码与状态。
- 所有扫描结果按实际结果披露；RUSTSEC-2023-0071 仍存在于依赖清单，不作为“已修复”处理。
