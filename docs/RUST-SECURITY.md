# Rust 版本安全边界与依赖告警

主控 0.10.0，Agent 0.2.2。应用源码禁止 unsafe；底层操作系统与密码库仍属于依赖信任边界。Rust 不能消除配置错误、权限滥用或所有逻辑漏洞。

## RUSTSEC-2023-0071 / CVE-2023-49092

主控依赖树中 `rsa 0.10.0-rc.18` 被 Cargo Audit 标记为 Marvin 时序侧信道告警，上游目前没有修复版本。原始扫描必须保留。官方公告：https://rustsec.org/advisories/RUSTSEC-2023-0071.html

本程序是 SSH 客户端，不提供 RSA 私钥解密或 RSA 私钥签名服务：首次部署使用密码认证；受管 SSH 私钥只生成 Ed25519；读取历史私钥后，在认证和建立 Agent 隧道之前检查算法，非 Ed25519 拒绝使用。RSA 特性仅为已有服务器的 RSA-SHA2 主机公钥验签保留。应用不配置 RSA 客户端私钥，也不支持导入任意管理私钥。

据此，当前应用路径没有该告警所描述的 RSA 私钥运算入口；这是针对当前代码和配置的可达性判断，不代表上游包已修复。未来增加 RSA 私钥、SSH 服务端或通用密钥导入时必须重新评审。

## 主要保护

- TLS 验证证书链与主机名，Agent 使用 WSS、独立节点密钥；禁止跳过证书验证。
- 管理密码 bcrypt，登录限流持久化；TOTP 启停需验证当前身份，动态码防重放。
- 管理接口要求有效会话；写操作校验 Origin 和 CSRF；Cookie 使用 Secure、HttpOnly、SameSite=Strict。
- 内部 HTTP 仅回环监听，PHP 网关凭证由私密主密钥派生；健康接口也验证凭证。
- 首次部署核对并固定 SSH 主机指纹；变更后拒绝连接。
- 终端票据短期有效、单次使用并绑定管理会话；退出、密码或 MFA 变更撤销活动终端。
- Agent 隧道仅连接节点回环 SSH 端口；消息大小、连接数、速率、队列和失联等待均有界。
- SFTP 按登录 SSH 用户权限操作；编辑仅限 256 KiB UTF-8 普通文件，校验版本冲突、保留权限与扩展属性，临时文件原子替换，不生成原文件备份。
- 节点凭据及 Telegram Token 使用 AES-256-GCM 加密，状态写入使用 0600 临时文件、同步与原子替换。
- 无数据库服务；storage 必须位于 public 外。独立 PHP 用户优于多站共享账户。

测试报告记录实际验证范围。快速扫描和压测不能保证不存在未知漏洞，也不等同于长期稳定性认证。


## 0.5.0 新增边界

- 恢复码高熵、单次使用、仅保存摘要；恢复登录撤销已有会话。root 重置 MFA 必须停本实例并手工确认。
- 加密备份具备完整性认证及解压大小限制；恢复采用持久提交日志，旧版历史字段在新版中仅兼容读取并丢弃。
- 跨域迁移必须匹配 SSH 指纹、恢复密钥和旧节点 Token，成功后轮换全部节点凭据。
- 在线删除只清理本 Agent 配置、公钥和服务；离线删除不排队执行远程命令。
- 根权限更新器不接受任意 URL、脚本或目录；发布签名与归档路径均验证，失败回退代码与状态。
- 所有扫描结果按实际结果披露；RUSTSEC-2023-0071 仍存在于依赖清单，不作为“已修复”处理。

## 0.6.0 新增边界

文件传输通过现有 Agent WSS 与 SSH 通道，限制为单会话一项传输、单文件 128 MiB；分块、偏移及传输标识校验，取消时尽力清理临时文件。上传和重命名拒绝同名覆盖。进程与服务查询采用固定命令，服务名白名单校验，不接受任意执行参数。

异地备份仅接受公网 HTTPS，解析后固定连接 IP、禁止重定向与环境代理。存储凭据加密保存，备份在本地加密后上传；下载与上传读回均校验 SHA-256。敏感操作仍要求近期身份验证，后台轮询仅返回脱敏状态。


## 0.7.0 新增边界

主题配置写入与预览均要求管理员会话及 CSRF 校验；图片仅接受有界 PNG/JPEG/WebP，服务端解码后重新编码，禁止 SVG/HTML 上传。局部 CSS 使用限定选择器、属性和值范围，禁止外部资源与执行内容。主题配置随加密备份保存，恢复时重新校验。金额以整数最小货币单位计算，支出与供应商信息仅在管理接口公开。安装与更新保留 SELinux enforcing，按限定目录恢复标签。


## 0.8.1 新增边界

SSH 使用普通 PTY shell；断线、关闭、退出或撤权均结束对应连接，不创建、附着或自动恢复 tmux。旧版 terminal-sessions 接口已移除，旧 resume 握手被拒绝。升级仅清理本面板 0.8.0 记录的独立 socket 和精确会话名；不会清理其他 tmux。

文件续传记录与节点、随机文件工作区、管理员登录会话和认证版本绑定；同一工作区只能由一个连接使用，断线后最多保留 30 分钟，私密存储 0600；上传临时文件的路径只能由服务器生成。恢复核对客户端和远端前缀 SHA-256，完成上传再次核对完整远端文件。每项传输按 128 KiB 分块，文件最多 2 GiB；浏览器队列、服务端记录和活动通道均有数量上限。编辑仍限制 256 KiB，并保留冲突检测、不生成原文件备份。

下载缓存位于浏览器 OPFS。下载 Service Worker 只在 /assets/ 下响应随机、单次使用的附件地址，通过授权页面专用 Worker 的 MessagePort 接收有界数据流，不读取 OPFS、不代理其他接口、不缓存页面。页面 CSP 仅补充同源 worker-src 与 frame-src；仍禁止第三方脚本、跨站嵌入与对象内容。浏览器本地缓存同样属于管理员设备数据，请保护设备和浏览器账户。

一次性接入命令有效 10 分钟，主控只存临时凭据摘要；原子领取后不可重放，管理员登出、撤权、重新生成或撤销会使未提交的授权失效。公开领取接口使用临时 bearer 凭据并限流，无需浏览器 Cookie；生成和撤销接口继续校验管理员身份与 CSRF。安装包由主控从签名发布清单和已校验二进制生成，经 HTTPS 传送；归档严格限制名称、类型、数量和大小。

## 0.9.0 主题包

主题导入和导出要求管理员身份；导入另校验 CSRF 与 Origin。主题包仅接受 3 MiB 以内的 JSON 数据，拒绝未知字段、脚本、文件路径、嵌套运行信息、外部资源地址与不支持的版本。导入只返回规范化的预览；保存再检查当前版本并写入配置。图片有解码尺寸、内存和并发限制，重新编码后保存。明暗配色仅能设置列出的颜色变量，局部 CSS 继续采用选择器、属性和值白名单。主题不能加入 HTML、JavaScript、PHP 或任意 CSS。导出只包含外观数据。

山水四季的既有设置与旧备份在载入时迁移为四季，随后进行原有验证。此版本不改变节点密钥、WSS 认证或 SSH/SFTP 协议。


## 0.9.1 终端连接

已授权且心跳正常的终端不会因为 10 分钟没有键盘输入或累计输出 64 MiB 而结束。输出仍限制为每秒 256 KiB，保留有界队列、输出确认及浏览器 2000 行回滚上限。主控每 25 秒发送 WebSocket Ping，75 秒未收到对应 Pong 才判定失联，重试不会延长失联期限。有效 Pong 仅更新既有授权的活动时间，不延长登录的 8 小时绝对期限，也不能恢复已撤销的会话。SSH 使用协议心跳检测存活。关闭窗口、主动断开、退出登录、凭据撤销和真实断线仍会结束远端 shell；不恢复已移除的终端保留或自动重连功能。操作记录包含关闭原因与连接秒数，不记录终端内容。

## 0.9.2 心跳隔离与有限重连

终端输入由独立任务按顺序写入 SSH，最多缓存 16 条、每条不超过 16 KiB；超量关闭，不建立无界缓冲区。WebSocket 接收循环不再等待 SSH 写入、窗口调整或文件错误响应，从而持续处理 Pong、输出确认和关闭消息。心跳及 Pong 使用独立有界队列，在发送任务中优先处理；控制帧另限速为每秒 16 条。网络本身持续不可写时仍按期限关闭，不承诺在物理网络中断时维持传输。

浏览器仅对暂时性传输故障，按 2、5、10 秒最多重试三次；连接稳定 60 秒后恢复重试额度。每次重新申请绑定当前登录的单次票据，建立全新 SSH 会话，不恢复旧 shell、不重发输入。主动关闭、取消、正常远端退出及明确认证失败不自动重连。取消与过期回调不能在标签移除后新建连接。所有重试继续受既有权限、连接数量、请求频率、主机指纹和登录绝对期限约束。

节点延迟探测的迟到、重复或不匹配 Pong 不再直接撤销整个 Agent 连接；只有当前挑战的及时应答可更新延时。有效监控数据的 15 秒期限、消息校验与速率限制保持生效。操作记录补充节点连接错误原因，不记录令牌或终端内容。


## 0.10.0 独立 Rust Web 与受限 Shell 恢复

Nginx + Rust 版将公开静态资源嵌入主控，不把文件系统路径映射为 URL。Nginx 仅代理到回环地址，覆盖来源 IP 头并清除外来的内部网关头；静态、页面和 API 保留 CSP、安全 Cookie、认证与 CSRF/Origin 限制。安装器凭私有状态目录内的随机所有权链接、HttpOnly Cookie 和 CSRF 安装，单写入者与有界请求体防止并发覆盖，认证文件提交后锁定安装。包内不包含站点密码、节点凭据或签名私钥。

Shell 标识为随机 256 位，仍需要单次终端票据及原始管理员登录、认证版本、节点一致。标识只保存在终端页面内存，不放入 URL 或浏览器持久存储。不同登录不能接管或关闭彼此会话。断线保留五分钟；主动关闭、退出登录、设备撤销、绝对登录期限与后台清理继续生效。主控重启后不允许新登录接管旧会话。远端 tmux 使用本实例独立命名空间，过期任务按会话定位，仅处理本面板创建的 Shell。断线不会自动重发命令。

SSH 保活和重新协商分别计时；重新协商期间不发送普通保活请求，不累计保活失败，重新协商另限时 60 秒。变更只涉及上游 russh 的客户端调度，不修改加密算法、主机密钥固定、密钥交换或认证验证。补丁来源和范围见 source/vendor/RUSSH-PATCH.md；测试覆盖延迟重新协商、协商超时及正常保活无响应。

终端、浏览/编辑、传输使用各自按需建立的 SSH 连接，文件超时只关闭文件连接。所有通道仍有有界队列、速率限制、授权检查和同一 Agent 的连接数限制。扩大连接上限不取消流控。

两个发行版的 root 更新器根据受信任配置选择 v* 或 rust-v*，拒绝跨发行版清单与归档；私有状态必须位于专用实例目录的 control 子目录。签名、长度、哈希、解压路径验证与失败回退继续启用。扫描范围、已知 RSA 告警与实测边界见本版本验收报告，不能据此保证不存在未知漏洞。
