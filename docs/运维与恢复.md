# 羽迹探针 0.5.0 运维与恢复

主控 0.5.0，Agent 0.2.0。已有站点升级时保留完整 `storage/`，不要重新安装向导。敏感操作要求近期密码验证；开启二步验证后，还需动态码或未使用的恢复码。

## 恢复码与丢失验证器

启用二步验证后显示 10 条恢复码，每条有 128 位随机熵，只能使用一次。服务端仅保存摘要。请下载到密码管理器，勿放入公开源码。

登录时输入正常密码，在验证码栏填写恢复码；恢复登录会撤销原有管理会话。进入“面板设置”，用密码和另一条未使用的恢复码关闭旧验证器，再绑定新设备。“账户安全”可以重新生成恢复码，旧批次立即失效。

恢复码也遗失时，使用服务器 root SSH。先停止本实例服务，命令会拒绝在服务锁占用时执行。

Debian 一键安装示例：

~~~sh
systemctl stop yuji-probe.service
/opt/yuji-probe/bin/probe-linux-amd64 --reset-mfa -state /var/lib/yuji-probe/control
systemctl start yuji-probe.service
~~~

按提示手工输入 `RESET MFA` 才会执行。arm64 改用 probe-linux-arm64。用户名、密码保持原值；验证器及恢复码清除，旧会话失效。

宝塔独立 PHP 服务示例：

~~~sh
systemctl stop yuji-probe-php.service
/www/wwwroot/probe/bin/probe-linux-amd64 --reset-mfa -state /www/wwwroot/probe/storage/control
systemctl start yuji-probe-php.service
~~~

路径及服务名须替换为实际实例。共享 PHP 环境应先停用本站入口，再停止其通信进程，防止访客请求重新启动；不要停止其他网站。

## 登录设备与节点权限

“账户安全”显示来源 IP、浏览器、登录时间、最近活动和远程会话数。撤销设备时关闭其身份和 SSH/SFTP 连接。真实 IP 应按可信代理配置获取，不能无条件相信访客转发头。

| 目标 | 终端 | 文件 |
| --- | --- | --- |
| 仅监控 | 关闭 | 关闭 |
| 严格只读 | 关闭 | 只读 |
| 完整管理 | 允许 | 浏览与编辑 |

“节点策略”由服务端执行，保存时关闭现有远程会话。允许终端时管理员仍可通过命令修改文件，因此严格只读必须同时关闭终端。

## 加密备份

在“备份迁移”填写不少于 12 字节的口令，下载 .backup。包含账户、站点、节点凭据、SSH 指纹、通知、命令、策略、账期及历史；不包含 Nginx/PHP、HTTPS 证书或其他应用文件。

使用 PBKDF2-HMAC-SHA256（600000 次、随机盐）与 AES-256-GCM。口令错误或密文篡改时拒绝导入。备份与口令分开保管，遗失口令无法解密。

自动备份周期为 6/12/24/168 小时，保留 1–30 份，位于私有 `storage/control/backups/`。自动备份口令由面板主密钥加密保存。请定期下载到其他设备，同机备份无法覆盖磁盘丢失。

压缩加密数据约 16 MiB、解压明文 128 MiB 上限；超过限制明确报错。更大实例可停本实例后另外加密备份完整 storage。恢复提交日志覆盖核心配置与历史，进程中断后在启动时继续提交。

## 新服务器、新域名迁移

1. 旧主控先将节点升级为 Agent 0.2.0，确认上线，安装专用 SSH 恢复公钥。
2. 导出加密备份。尽可能停止旧主控，避免双主控争用。
3. 新服务器解析域名、配置有效 HTTPS，完成新安装向导。
4. 登录“备份迁移”，选择旧备份、口令，确认恢复。
5. 用备份中的管理员及二步验证重新登录，在“版本管理”查看迁移状态。

新站保留当前 origin；域名变化时经固定 SSH 指纹及专用恢复密钥主动连接节点，更改 WSS 地址，轮换 Token、终端密钥及恢复密钥。节点确认新 WSS 正常后完成；目标不可达则回到原配置。

旧主控不可达仍可恢复，但需要备份含匹配的恢复密钥、节点已安装对应通道、SSH 可从新主控到达、SSH 指纹未变化、新域名 DNS 和证书有效。旧 Agent 缺少恢复通道或 SSH 不可达时任务会提示并可重试，也可填写 SSH 密码重新部署；不会绕过证书或指纹验证。

同域名迁移可在恢复备份后切换 DNS，避免旧主控同时在线。修改页面站名不等于更换连接域名。

添加已有 Agent 的服务器并通过 SSH 密码验证后，自动替换本项目连接配置和专用密钥，保留其他公钥；失败恢复之前的 Agent 配置与运行状态。

## 历史、账期和告警

管理员详情有 24 小时分钟采样及 7/30 天 15 分钟采样，可切换 CPU、内存、磁盘及网速。上下线记录与离线时间仅覆盖已观测区间；定点采样可能遗漏短时尖峰。

默认按物理网卡累计流量，可明确指定网卡。每月 UTC 1–28 日选择账期起点，按上传、下载或双向累计；重启、计数器归零后继续累加。修改网卡集合或账期日会开启新统计段。

首次接入前、离线中跨越重启的数据无法补算，持久化间隔内整机故障也可能丢失最近样本。这是监控参考，不等同于供应商账单。

资源持续超限后发送 Telegram，支持恢复通知、重复间隔及同批聚合。先配置并启用 Telegram。维护窗口内暂停该节点上下线与资源告警，历史继续采集。主控自身故障的外部提醒不在本版本范围。

## 移除节点

在线：下发固定清理操作，停用本 Agent、删除连接配置及面板专用 SSH 公钥，确认后删除记录。用户文件、其他应用与其他公钥保持不动。

离线：立即删除本地记录和凭据，不生成远程清理任务。服务器恢复后旧 Token 不能重新登记，需重新添加部署。

## Agent 更新与回退

“版本管理 → 升级 Agent”从固定 GitHub 仓库下载预编译资产，验证 Ed25519 签名、SHA-256、大小、架构及版本后安装。WSS 健康检查失败时回到原二进制与配置。

旧 Agent 通过已有终端通道安装受限管理入口。“回退 Agent”需要有效历史二进制和签名清单，首次安装没有上一版会明确提示。

## 主控签名更新器

Debian 一键安装自动配置。后台只提交固定操作与版本号，由 root 所有的 helper 从 coexacx/yuji-probe 下载已签名包。浏览器不能选择任意路径、命令、仓库或下载地址。

更新前保留程序和私有状态快照，仅停止本实例服务。健康检查失败时恢复；手动回退也恢复当时数据，所以更新后的密码、设置或统计可能丢失，先导出最新备份。

宝塔环境先为本站建立独立 PHP-FPM 或主控服务。假设服务为 yuji-probe-php.service，root 核实后执行：

~~~sh
python3 /www/wwwroot/probe/ops/update-panel.py --configure \
  --name probe --root /www/wwwroot/probe \
  --state /www/wwwroot/probe/storage/control \
  --service yuji-probe-php.service --origin https://probe.example.com \
  --listen 127.0.0.1:19281
~~~

不要填写所有网站共享的 PHP 服务。核实服务 ExecStart、KillMode=control-group、内部端口均只属于本站。更新器位于 /usr/local/lib/yuji-probe-updater/，root 配置在 /etc/yuji-probe-updaters/，回退快照在 /var/lib/yuji-probe-updater/。未安装 helper 时监控及 Agent 管理正常，主控仍可按宝塔教程手动更新。
