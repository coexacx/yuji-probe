# 0.8.0 功能与验收

测试日期：2026-10-01。主控 0.8.0，Agent 0.2.1。本次保持 Agent 协议和二进制不变，新增能力由主控、浏览器和远端 tmux 完成。

## 实现内容

- 终端保活和恢复：保留并退出、意外断线自动重连、刷新后手动恢复；关闭和结束会话终止远端会话。主控重启后可重新登录并恢复尚未到期的 shell。
- 文件顺序队列、暂停与续传；128 KiB 分块，单文件上限 2 GiB。下载使用 OPFS 与流式保存，避免拼接完整文件；续传及最终上传校验 SHA-256。
- 在线编辑加入行号、语法高亮、查找替换、撤销重做、换行及保存前差异预览；保留 256 KiB 限制、冲突检查，不备份原文件。
- 一次性 Agent 接入命令：10 分钟、单次领取、可撤销，可更正已有离线节点的主控信息。
- Ctrl、Tab、Esc 等手机快捷键点击反馈；Ctrl 开关状态仍独立显示。

操作与环境要求见[终端与文件操作](终端与文件操作.md)。

## 实际功能测试

测试站采用 HTTPS / WSS、Rust 主控、Nginx、PHP-FPM；真实被控为 Debian 12 amd64。通过浏览器实际连接 SSH/SFTP，测试：

- 保留退出后恢复环境变量、网络断开后恢复、主动关闭后新 shell 不继承旧环境。
- 主控重启、重新登录、恢复原 shell；显式结束后会话清理。
- 达到节点连接上限时拒绝新连接，不泄漏保活会话名额；已附着会话不可被另一窗口接管。
- 多文件上传队列、10 MiB 上传中断续传、192 MiB 真实下载中断续传及完整 SHA-256。
- 页面刷新后恢复终端，重新选择原文件完成 6 MiB 上传续传，远端完整哈希匹配。
- 浏览器取消最终保存后，使用磁盘缓存重试，32 MiB 导出文件完整哈希一致。
- 文件选择器取消不关闭 SSH；管理员登出后终端撤权，界面不重复发起结束请求。
- 节点重新上线后，旧窗口可点击连接向服务端重新核验，不因初次离线状态永久锁定按钮。
- 文件编辑行号、高亮、差异确认和保存；手机 Ctrl / Tab / Esc 点击反馈，无未处理页面异常。
- 在已有 Agent 的测试节点实际执行一次性接入，服务上线、WSS 信息正确；同一命令再次提交返回 401。

## 内存测试

同一测试机 Chrome 普通持久浏览器上下文，分别启动新浏览器进程；按进程树 Private_Clean + Private_Dirty 采样，以下为扣除预热基线后的新增内存峰值。旧方案保留分块数组并创建 Blob，新方案按块写 OPFS 后流式导出。

| 方法 | 文件大小 | 新增内存峰值 |
| --- | ---: | ---: |
| 旧数组 / Blob | 192 MiB | 454.8 MiB |
| OPFS / 流式保存 | 192 MiB | 94.3 MiB |
| OPFS / 流式保存 | 512 MiB | 144.2 MiB |

192 MiB 同规模对照下降约 79%。这是本测试机的浏览器进程数据，不是手机硬件实测或通用内存上限。512 MiB 为浏览器缓存与导出测试，真实 SSH/SFTP 下载实测到 192 MiB；2 GiB 为经边界验证的配置上限，未声称完整实传 2 GiB。无痕环境可能将临时文件保存在内存中，因此不用于上述对比。

## 有界压力回归

独立回环测试实例，与测试站和生产站的数据、端口分离。200 个模拟节点同时上报，200 个并发客户端访问；主控限制 1 核、512 MiB，测量阶段 20 秒。

- 请求 15,975 次，错误 0，成功吞吐约 789.7 请求/秒。
- P95 延迟约 309.7 ms；结束时 200 个节点在线且最新上报内容全部匹配。
- 主控峰值 RSS 19.21 MiB、平均单核 CPU 41.08%，无 OOM。

这是快速回归，不能替代长期压测，也不能推定任意机器都达到同样吞吐。

- Rust 单元测试 37 项通过，Clippy 全目标警告作为错误检查通过；现有前端测试 6 项通过，PHP 语法通过。
- npm audit：0 个已知依赖告警；Agent cargo audit：0。主控仍有已有的 RUSTSEC-2023-0071 RSA 告警，见[安全边界与可达性说明](RUST-SECURITY.md)，未宣称已修复。
- 源码密钥扫描未发现泄漏；发布包通过 3 份发布签名、1,939 条文件校验和、私密目录排除和 282 个静态资源引用检查。压缩包扫描的 8 项命中均逐条核验为 SHA256SUMS.json 中的公开文件摘要，实际凭据泄漏 0 项。
- 未登录管理和终端访问被拒绝；缺失 CSRF、跨站写入、私有文件访问、CSS 注入及伪装图像被拒绝。
- 续传错误前缀、远端内容篡改、跨终端续传、非法文件名和超限尺寸被拒绝。
- 一次性接入的撤销、伪造和重放被拒绝；公开安装脚本不含节点凭据。
- 下载附件地址单次有效；重复及不存在的随机地址返回 404。
- 退出登录后活动终端和恢复入口失效，下载导出可以被取消，不代理管理接口或读取其他缓存。

amd64 在真实节点验收；ARM64 完成交叉编译，不视为本次 ARM64 真机验收。以上说明实际测试覆盖范围，不能保证不存在未知漏洞。
