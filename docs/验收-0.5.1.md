# 0.5.1 变更与验收

日期：2026-09-30。主控与界面 0.5.1，Agent 继续使用 0.2.0。安装方式不变，升级应保留 storage；无需重新部署 Agent。

## 功能精简

直接移除“节点策略”的界面、配置接口、数据模型与执行逻辑，包括资源阈值、维护窗口、按节点终端与文件开关、网卡选择及流量账期。旧策略不再影响现有管理员操作。SSH/SFTP 继续校验管理员身份、有效会话、节点在线状态、主机指纹及远程系统账户权限。

移除详情中的“历史与流量”及长周期采样、持久化任务。保留实时指标、短时 CPU 趋势、网卡速率和系统累计收发流量。旧接口不再提供功能。旧备份中的历史、策略、告警状态被忽略，新备份不输出这些字段；升级前私有目录中的历史文件不再读写。

## Telegram

上线、离线、续费和测试通知使用明确的状态标题、站点、服务器、UTC+8 时间及“打开面板”按钮。续费继续按同日到期聚合，最多列出 20 台，其余以数量提示。

后台提供消息预览、事件选择和投递状态；可选管理员登录提醒默认关闭。预览不会发送通知。名称先限制长度再转义 HTML，浏览器只重建允许的格式标签。Token 加密保存、接口不返回明文。离线防抖、重试、限流与续费抑制逻辑保留。

格式采用 [Telegram 官方 HTML 模式](https://core.telegram.org/bots/api#html-style)。

## 快速负载回归

独立回环测试实例，200 个模拟 Agent 经 WSS 上报，同时 200 个客户端访问，测量 20 秒。约 831.0 次成功请求/秒，16,807 次请求，0 错误；P95 283.7 ms；200 个节点在线且最新上报全部匹配。主控平均 RSS 18.1 MiB，CPU 约单核 47.8%，无 OOM。

这是短时回归测试，不是长期稳定性或公网容量上限。沿用同一测试条件和速率限制；指标见 [原始汇总](performance-0.5.1.json)。性能对照沿用 [0.5.0 报告](验收-0.5.0.md)，本次不重新宣称 Go/Rust 对照结论。

## 扫描与限制

npm audit 未发现漏洞，源码密钥扫描未发现泄露。Cargo Audit 仍报告 RUSTSEC-2023-0071（rsa 0.10.0-rc.18），这是已有的上游告警，未被本次修改修复。程序只使用 Ed25519 管理私钥，RSA 保留用于服务器主机公钥验签；可达性判断与限制见 [安全说明](RUST-SECURITY.md)。

扫描与上述测试覆盖本次改动及主要功能，不能证明不存在所有未知漏洞。生产部署后的节点与真实 Telegram 投递结果单独记录在部署验收文件中，不包含账户密码或 Bot Token。
