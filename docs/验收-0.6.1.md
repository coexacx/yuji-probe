# 羽迹探针 0.6.1 验收记录

日期：2026-10-01。主控与界面 0.6.1，Agent 沿用 0.2.0。开发、编译与写入测试在开发环境完成。

## 变更

- 修复取消文件选择时整个 SSH 工作区关闭：外层终端仅处理以自身为目标的 cancel / close 事件。
- 文件侧栏新增“新建文件”，创建空文件后进入编辑；沿用既有 SFTP 上传的认证、路径校验、私有权限和禁止覆盖机制。
- SSH 标签按当前打开顺序连续编号。关闭标签后自动重新编号，全部关闭再打开从 1 开始；内部会话 ID 与显示编号分离，保留连接和终端状态。

## 浏览器与真实 SSH 验证

Chrome 无头浏览器、真实 WSS / SSH / SFTP 连接；桌面 1440×1000 和手机尺寸 390×844。手机尺寸测试不等于 iOS / Android 真机验证。

修复前捕获到浏览器生成的可信 INPUT cancel 事件，确认终端关闭及 WSS 断开。修复后完成 12 组检查：

1. 连续取消原生文件选择，两个 SSH 会话保持连接，shell 变量仍存在。
2. 粘贴命令、新建目录子弹窗按 Escape 只关闭对应弹窗。
3. 取消文件选择保留未保存的编辑，不触发终端关闭确认。
4. 主动关闭终端仍有未保存内容保护，取消确认可继续编辑。
5. 取消正在上传的文件会清理临时传输，SSH 可继续执行命令。
6. 正常上传、下载的内容逐字节相同。
7. 新建文件可取消、校验名称、自动打开、保存；拒绝覆盖同名文件、目录、符号链接。
8. 创建另一文件后拒绝切换时，之前未保存的编辑仍保留。
9. 系统运行目录拒绝创建文件，SSH 连接不受影响。
10. 手机尺寸下取消选择、多标签切换、新建文件及保存正常，无横向溢出。
11. 关闭再打开标签、关闭第一个标签后的重新编号、全部关闭后从 1 开始；编号变化保留原 shell 状态。
12. 浏览器无 JavaScript 错误。

测试节点独立目录检查：原文件内容与符号链接保持不变，新建文件权限 0600；取消创建、取消上传均无残留文件或传输临时文件。
