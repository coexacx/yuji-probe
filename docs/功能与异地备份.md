# 0.6.0 文件、运行状态与异地备份

本版沿用 PHP 8.0+、Nginx 和 Rust 主控，Agent 协议不变，配套 Agent 仍为 0.2.0。不需要数据库或额外端口。

## 分组与排序

管理后台 → 服务器 → 编辑：可填写分组，勾选置顶，并填写最多 2000 字的私有备注。分组和置顶在公开看板显示；备注只在管理员详情和编辑表单显示。

服务器列表可拖动行排序；手机和键盘用户可使用上移、下移箭头。公开看板“默认排序”先显示置顶节点，再按保存的顺序显示。“全部分组”可筛选分组，搜索也支持分组名称。

## 多标签 SSH

进入任一服务器的 SSH 窗口，点击连接。顶部选择另一台在线服务器，点击“新建标签”；也可为同一台服务器建立另一条连接。每个浏览器工作区最多 4 个标签，主控同时接收最多 8 条 SSH / 运行状态连接。

切换标签保留终端输出、连接和未保存的文件内容。标签上的 × 或右上角“关闭”仅关闭当前标签。按 Esc 关闭整个工作区；有未保存内容或传输任务时先确认。退出登录或撤销设备会话会结束所属终端。关闭页面或网络中断可保留 tmux 会话 30 分钟，详情见[终端与文件操作](终端与文件操作.md)。恢复不会重复执行历史命令。

## 文件管理

SSH 连接成功后，左侧文件面板提供目录浏览、新建目录、重命名、上传和下载。手机点击“文件”展开侧栏。文件行的 ↓ 下载文件，⋯ 重命名。普通 UTF-8 文本仍可点击后在线编辑。

- 单个上传或下载文件最大 128 MiB，分块传输；在线编辑最大 256 KiB。
- 上传和重命名拒绝覆盖同名目标。上传先写独立临时文件，完整传输后再提交。
- 取消或断开连接时尝试清理本次上传的临时文件。节点突然断网或关机时无法保证立即清理，可能留下权限为 0600 的 .probe-upload-* 文件；管理员确认无活动传输后可手工删除。
- 在线保存保持原有的并发修改检查，不备份原文件。
- 路径权限以配置的 SSH 用户为准；不提供对 /proc、/sys、/dev、/run 的写入或重命名操作。
- 下载的是普通文件；符号链接会解析到其普通文件目标，不递归打包目录。浏览器在本地接收下载内容，手机处理大文件时要预留内存。

## 进程、服务与日志

管理员服务器列表点击“运行状态”，或在详情点击“查看进程与服务”。

进程页面每 5 秒刷新，显示 CPU / 内存排序前 100 项；最多采集 4096 个进程。CPU 首次采样后需要下一次采样才能计算使用率，按单核 100% 计，多线程进程可以超过 100%。内存为 RSS。

系统服务展示 systemd 当前已加载的服务；“查看日志”读取指定服务最近 100 行 journal。服务列表与日志按需读取，可手动刷新。页面只读，不提供结束进程、重启服务或任意查询命令。采集经原 Agent WSS 中继下的 SSH 通道进行；日志权限由 SSH 用户决定。普通用户未加入 journal 访问组时可能看不到全部日志。

## S3 / WebDAV 异地备份

在“备份迁移”先保存“自动备份口令”，再填写“异地备份”。自动周期可为每 6 小时、12 小时、每天或每周；手动“立即备份并上传”也使用该口令。自动周期关闭时，仍可手动备份上传。

备份先在主控加密，再上传。格式继续使用 AES-256-GCM、随机盐和随机 nonce，PBKDF2-HMAC-SHA256 600,000 次派生密钥。**备份口令需要独立保存，丢失后无法解密。** 存储凭据由主控密钥加密保存，接口不返回明文密钥；留空保留已有密钥。

### S3 兼容存储

填写：

- HTTPS 存储地址：例如 https://s3.us-east-1.amazonaws.com 或服务商给出的 S3 API 地址，不填写控制台地址。
- Bucket：已存在且已授权的存储桶。
- Region：按服务商要求填写；部分兼容存储使用 auto 或 us-east-1。
- Access Key ID / Secret Access Key：专用于备份的访问凭据。
- 目录前缀：例如 yuji-probe/main。名称采用英文字母、数字、点、下划线或短横线，可用斜线分级，最多 8 层、240 字节。
- 远端保留份数：1–30。

采用 AWS Signature V4、路径式请求 endpoint/bucket/prefix/file。需要 GetObject、PutObject、DeleteObject 权限，限定到指定 Bucket / 前缀即可。不需要列出整个桶的权限。本版不支持 STS 临时会话 Token 或只支持虚拟主机式访问的服务。

### WebDAV

存储地址填写已有的 WebDAV 基础目录，例如 https://cloud.example.com/remote.php/dav/files/backup-user 。填写用户名、密码或应用专用密码；目录前缀会通过 MKCOL 创建。权限须允许创建子目录以及读、写、删除文件。

### 验证、重试与恢复

先保存配置，再点击“测试已保存配置”，面板依次写入随机测试文件、读取比对并删除。然后点击“立即备份并上传”；“最近成功”更新且出现备份记录时表示上传及读回 SHA-256 校验已通过。

网络或存储故障时保留本地备份并显示错误，按退避间隔最多尝试 5 次，可在修复配置后点击“重试上传”。“立即备份并上传”生成新快照。仅轮换面板记录的备份文件，不删除存储桶或目录中的其他文件。切换存储地址、类型、Bucket 或前缀会清空面板中的旧目标索引，但不会删除旧目标中的文件；如需再次导入这些旧备份，请从原存储下载。

下载按钮只下载当前目标的已记录备份，并核验长度和 SHA-256。下载后在“恢复与迁移”选取 .backup，输入备份口令并确认恢复。新主控会重新加密存储凭据；域名改变时继续通过原有专用 SSH 恢复密钥更正 Agent 的连接信息。

备份仅包含面板配置和节点连接信息，不包含被控服务器文件、操作系统或第三方存储本身。安装到新主控后，即使本地备份索引丢失，也可从服务商下载 .backup 后导入。

地址仅支持公网 HTTPS，校验证书、禁止跳转和环境代理、解析后固定连接 IP，拒绝本机、内网及保留地址。不支持自签证书或内网 NAS 地址。生产站点默认关闭异地备份，需要管理员填写自己的存储凭据。S3 服务商兼容性应先通过上述测试确认。

协议参考：[AWS S3 SigV4](https://docs.aws.amazon.com/AmazonS3/latest/API/sig-v4-header-based-auth.html)、[WebDAV RFC 4918](https://www.rfc-editor.org/rfc/rfc4918.html)。
