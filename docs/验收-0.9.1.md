# 0.9.1 终端长连接修复与验收

日期：2026-10-02。主控与界面 0.9.1，Agent 0.2.1。

## 问题与修复

旧版只把键盘输入及文件操作计作活动：空闲连接约 603.2 秒后关闭，持续输出日志也不能避免这一限制。另有累计输出 64 MiB 的硬上限，实测约 258.7 秒时触发。WebSocket 心跳只等待 5 秒，12 秒应答延迟也会触发断开。历史关闭记录未区分具体原因。

新版移除终端无输入计时和累计输出量上限，保留每秒 256 KiB 输出限速、有界队列、确认窗口、连接数和浏览器 2000 行回滚上限。每 25 秒发送心跳，75 秒未收到匹配应答才判定失联；重试不会重置失联期限。有效心跳更新既有会话活动时间。SSH 协议心跳检测连接存活。操作记录增加关闭原因和连接时长，浏览器显示服务端关闭原因。

管理员登录的 8 小时绝对期限仍有效；退出登录、撤销权限、关闭窗口、主动断开和真实网络中断仍会结束远端 shell。重新连接会建立新的 shell，没有重新加入终端保留、后台 tmux 或自动断线恢复功能。Agent 通信协议不变，既有 Agent 无需重新安装。

## 实测

| 场景 | 结果 |
| --- | --- |
| 真实节点空闲连接 | 持续 679.6 秒，随后命令正常执行 |
| 持续输出 | 接收 80.001 MiB，完成标记与后续命令均正常 |
| 心跳应答延迟 12 秒 | 保持连接，后续命令正常 |
| 持续错误心跳应答 | 在固定失联期限后断开并提示原因 |
| 主动断开、关闭、退出登录 | 连接关闭；关闭后远端 shell 已结束 |
| 再次连接 | 创建新 shell；没有恢复旧环境或自动重连 |
| 文件操作 | 新建、编辑保存、上传哈希、取消上传均通过 |
| 手机快捷键 | Ctrl、Tab、Esc 反馈正常 |

长连接测试期间主控合计 RSS 采样峰值约 15.93 MiB。独立的 200 模拟节点、200 并发客户端短时回归共完成 11624 次请求，错误 0，200 节点在线且最新数据全部匹配；本次约 572.10 RPS、P95 460.30 ms。压测期间测试站还保留两条真实终端连接，这不是与旧版本的严格性能对照。

## 安全与检查范围

Rust 45 项测试、前端 7 项测试、格式检查与 Clippy 通过。匿名终端访问、缺失/跨域 Origin、错误票据、跨登录使用票据、重复票据和旧 resume 协议均被拒绝。管理接口权限、CSRF、私密文件隔离、安全 Cookie、退出撤权等回归通过。源码密钥扫描没有发现秘密信息，npm 审计 0 条漏洞。

主控 Cargo Audit 仍报告已记录的 RUSTSEC-2023-0071（RSA 依赖）；本次没有变更依赖或宣称修复此上游问题。应用仅接受受管 Ed25519 SSH 私钥，RSA 用于主机公钥验签，可达性说明见 RUST-SECURITY.md。

AMD64 完成真实节点及浏览器测试；ARM64 完成交叉编译与 ELF 架构检查，未声称 ARM64 真机验收。心跳状态机另以模拟时间覆盖 24 小时循环，这不等于真实运行 24 小时。本报告的实际长连接观察时长如上，不保证不存在未知漏洞或网络、系统休眠及远端 SSH 策略引起的断线。安装方式保持原有 Nginx + PHP 8.0+ 流程。
