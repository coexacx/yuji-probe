# 0.8.1 终端保活移除验收

2026-10-01。主控及界面 0.8.1，Agent 保持 0.2.1。本版仅移除终端保活和断线恢复，并将文件续传工作区与 SSH shell 分离。

## 终端与文件实测

- 测试节点真实 SSH：普通 PTY shell，不进入 tmux；网络连接断开后原 shell PID 消失，8.5 秒观察内没有自动重连；手动连接产生不同 PID，原环境变量不存在。
- 移除恢复下拉框、保留并退出按钮、自动重连，以及旧 terminal-sessions API；旧 resume 握手由单元测试确认拒绝。
- 关闭按钮和退出登录结束连接；取消文件选择保留终端；手机 Ctrl / Tab / Esc 点击反馈保留。
- 6 MiB 上传在断线后通过新 SSH 会话续传，完整远端 SHA-256 一致；另一次 6 MiB 上传经页面刷新、重新选择原文件后续传，完整远端校验一致。
- 编辑器差异预览、保存与行号功能保留。下载缓存取消后重试的 32 MiB 测试校验一致，消费过和未知下载地址均拒绝。
- 旧版登记的面板 tmux 会话清理完成；独立测试 socket 中的非面板会话仍在运行。未卸载服务器上的 tmux。

## 安全与静态检查

Rust 38 项测试、Clippy 全目标零警告、前端 6 项测试、PHP/Python 语法检查通过。

权限验证覆盖未登录管理接口、CSRF、跨来源写入、Cookie 安全属性、私密目录、安装锁、公开数据隐私、CSS/图片输入、文件名与大小边界、上传内容篡改、其他文件工作区和其他管理员登录越权，以及退出后的连接撤销。

npm 与 Agent 依赖审计无已知告警；主控仍有 [RUSTSEC-2023-0071](https://rustsec.org/advisories/RUSTSEC-2023-0071.html)（rsa 依赖）既有告警，上游没有可升级的修复版本。当前 SSH 私钥使用 Ed25519，RSA 仅参与公钥/主机密钥验证；该项继续保留跟踪，不能将自动扫描结果表述为绝对无漏洞。源码凭据扫描无发现。

## 快速压力测试

隔离的本机 HTTPS 环境，200 个模拟 Agent 持续上报，同时 200 个客户端请求看板，测量 20 秒：

- 请求 14,961 次，错误 0，平均 737.66 次/秒。
- P95 334.73 ms；200 个节点均在线，最终最新数据全部匹配。
- Rust 主控峰值 RSS 19.23 MiB，平均 CPU 41.57%（单核为 100%），无 OOM。

该测试用于回归，不代表公网、长时间或真实手机的吞吐保证。ARM64 已交叉编译，未进行 ARM64 真机 SSH 实测。

## 部署

Nginx + PHP 安装流程保持不变，网页安装向导保留；本版已编译 amd64/arm64 主控。升级前结束工作中的终端并保存文件。SSH 连接终止不负责结束管理员自行通过 nohup、systemd 或独立 tmux 启动的任务。
