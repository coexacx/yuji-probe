## 本次交付

1. SFTP 文件上传、下载、新建目录与重命名。
2. 只读进程、systemd 服务与最近日志。
3. 分组、置顶、拖动/按钮排序和管理员私有备注。

5. S3 兼容存储 / WebDAV 加密异地备份、保留数量轮换、下载校验、失败重试和导入恢复。

网站/端口检测未加入；已移除的节点策略与长期历史功能不恢复。安装方式不变，使用 Nginx + PHP 8.0+，无需数据库。详细操作见[功能与异地备份](功能与异地备份.md)。

## 200 节点 / 200 客户端回归

受限独立进程环境下，200 个模拟 Agent 持续上报，200 个 HTTPS 客户端访问公开快照；计量阶段 20 秒。原始结果见 [performance-0.6.0.json](performance-0.6.0.json)。

- 成功请求 15,246 / 15,246，错误 0。
- 约 753.6 次请求/秒；P95 371.0 ms，P99 483.7 ms。
- 200 节点在线，最后一条上报全部匹配，测量期间接收 4,000 条监控上报。
- Rust 主控平均 CPU 48.7%（单核 100%），峰值 RSS 18.32 MiB，OOM 0。
- PHP 与 Nginx 使用独立 CPU 配额；RSS 含共享页，不能把各进程 RSS 简单相加作为独占内存。

这是短时回归，不是长期稳定性保证或公网容量承诺；没有据此重新宣称与 Go 的跨版本性能结论。

## 安全扫描

- npm audit：0 告警。
- Rust Agent cargo audit：0 漏洞告警。
- Rust 主控 cargo audit：仍有 RUSTSEC-2023-0071（rsa），没有新增告警。管理私钥使用 Ed25519，当前调用路径不进行受影响的 RSA 私钥运算；为兼容已有服务器的 RSA 主机公钥验证而保留相关依赖。此判断不等于上游包已修复，详情见 [RUST-SECURITY.md](RUST-SECURITY.md)。
- 源码 Gitleaks：0 条发现。最终安装包的独立校验、签名和扫描结果随发布的 verification-0.6.0.json 提供。
- 私有备注仅在管理接口返回；渲染使用文本节点。新文件操作继续要求管理员会话、单次票据与 Agent 身份认证。
- 服务名称拒绝 shell/选项注入；文件操作校验类型、大小、偏移、传输标识和目标名称，拒绝同名覆盖。
- 异地备份 HTTPS 使用原有显式 TLS 配置；DNS 公网校验后固定连接地址，禁止跳转与代理，密钥加密保存并不回显。
- 新功能的接口负例和真实操作已验收；不承诺不存在任何未知漏洞。
