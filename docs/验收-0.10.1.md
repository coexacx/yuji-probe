# PHP 版 0.10.1 终端修复验收

本次将独立 Rust 版 v0.10.2 的终端滚动修复同步至原 PHP 仓库。部署方式仍为 Nginx + PHP-FPM + 随包 Rust 主控，Agent 仍为 0.2.2。安装方式不变。

## 实际测试

在开发服务器的 Nginx + PHP 8.4-FPM 网关后使用 amd64 主控，连接真实 Linux 测试节点；Chrome 分别验证桌面与手机触摸布局。

- 400 行输出逐行核对，无丢失或重复；桌面鼠标滚轮、手机滑动、查找与选择有效。
- 阅读历史时新增输出不改变当前回看位置；恢复后原 Shell 标识和 400 行历史保持一致。
- 15,000 行突发输出完整接收；浏览器仅保留最近 5,000 行及当前屏幕，连接保持正常。
- 全屏程序退出后恢复历史；真实 less 运行中断线并恢复、退出后原回滚记录仍可读取。
- Ctrl+C、取消上传、独立 SFTP 列表、主动断开与关闭标签正常。
- 16 MiB 下载与目录浏览、终端输入同时进行；操作系统检查确认三条独立 SSH 连接。
- Agent 重启后恢复原 Shell 与运行中的命令；跨管理登录恢复/关闭被拒绝，主动关闭和退出登录销毁会话。
- 管理员授权、CSRF/Origin、安全 Cookie、私有路径、安装锁定、公开接口字段以及主题注入防护通过。

Rust 单元测试 61 项、SSH 协议集成测试 3 项、前端测试 14 项通过；Rust fmt/Clippy 和 7 个 PHP 文件语法检查通过。amd64 与 ARM64 主控均编译成功；ARM64 为交叉编译，不代表 ARM 真机验收。此次未重新执行一小时连接或 200 节点吞吐测试。

## 安全扫描

源码密钥扫描未发现泄露项，前端依赖审计无已知告警。Rust 依赖仍报告既有 RUSTSEC-2023-0071；受管私钥仅使用 Ed25519，RSA 保留用于主机公钥验签，详细边界见 [安全说明](RUST-SECURITY.md)。无新增依赖，不将扫描结果表述为不存在未知漏洞。

最终安装包的签名、文件校验、私密状态排除及 PHP 更新/回退结果见 Release 附件 verification-0.10.1.json。测试结束后开发预览恢复独立 Rust v0.10.2；本次同步不切换正式站的部署版本。
