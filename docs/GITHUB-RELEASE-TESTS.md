## 已知限制

- 主控依赖存在 **RUSTSEC-2023-0071 / CVE-2023-49092**，涉及 rsa 0.10.0-rc.18 的私钥计时侧信道。扫描时没有上游修复版本。当前托管私钥限制为 Ed25519，RSA 仅参与远端主机公钥验证；这是当前调用路径判断，不能表述为依赖告警已经修复。见 [Rust 安全说明](RUST-SECURITY.md)。
- ARM64 已交叉编译，但没有 ARM64 真机验收；Ubuntu 被控支持沿用原版，本次新增安装器只针对 Debian 12 / 13。
- 本轮是功能和安全边界验收，不是长期稳定性或最大容量保证。旧版 200 节点 / 200 客户端同条件比较中 Rust 主控内存较低，HTTP 吞吐低于 Go；本版没有修改该请求处理路径，不宣称性能差距已经解决。
- 短时扫描与测试不能证明不存在未知漏洞。

原版验收与性能比较仍保留在同目录，属于历史记录，不能代替本版新增安装流程的实际测试。
